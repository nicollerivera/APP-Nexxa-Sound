# Nexxa Staff

Aplicación de gestión logística para Nexxa Sound.

## Instalación

1. Clonar el repositorio.
2. Instalar dependencias:
   ```bash
   npm install
   ```

## Desarrollo

Para iniciar el servidor de desarrollo:
```bash
npm run dev
```

## Build

Para generar la versión de producción:
```bash
npm run build
```

El resultado se guardará en la carpeta `dist`.

## Despliegue en Vercel

Este proyecto está configurado para desplegarse automáticamente en Vercel usando el preset de Vite.
Simplemente conecta el repositorio y Vercel detectará la configuración.
